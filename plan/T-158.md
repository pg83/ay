# T-158: run source-resolution regressions through `ay make -G`

## Scope

Prove the graph-generation half of the binary-test migration by moving
`sources_test.go` to one Python test node over the production `ay` binary.  The
two regressions cover source-root paths, module-relative paths, and the
module-relative winner when both spellings exist.  All are observable in the
serialized CC node inputs; no production test hook is needed.

## Existing and public mechanisms

The Go tests currently construct a `newMemFS` and either call
`resolveSourceVFS` directly or inspect the graph returned by `testGen`.  The
public equivalent is the normal command path:

1. materialize the same file map below a temporary source root;
2. add the ordinary `.arcadia.root` marker and minimal `ya.conf` read by
   `cmdMake`;
3. run `ay make -j0 -G --sandboxing` for the fixture target;
4. parse stdout as the emitted graph and inspect CC inputs.

`--sandboxing` is required because graph dumps intentionally omit source-root
inputs otherwise.  Fixed Linux host/target platforms and `OPENSOURCE=yes` make
the synthetic graph independent of the developer host without introducing a
test-only production mode.

## Files and sequence

1. Extend `tst/lib.py` with `make(files, target, *args)` and a single
   `node_by_output` lookup.  The helper owns its temporary tree and calls the
   existing subprocess wrapper; it does not implement parsing, resolution, or
   graph generation itself.
2. Add `tst/test_sources.py`, preserving both source-resolution assertions in
   terms of serialized CC inputs.
3. Run `unit_sources` while `sources_test.go` remains present.
4. Remove `sources_test.go`, rerun the binary node and the remaining Go tests,
   then commit the completed file-for-file migration.

## Gate and performance

Run `./build unit`, then the full foreground `./build test`.  Validation parity
must be unchanged because production Go sources are untouched.  The new node
must be independently addressable and cached after success.  Its runtime must
remain small compared with the removed Go test compilation cost; a regression
outside the 5% noise band in the aggregate unit gate is not acceptable.
